# My Website

A modern, responsive personal website built with vanilla HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Interactive Navigation**: Mobile-friendly hamburger menu with smooth scrolling
- **Contact Form**: Functional contact form with validation
- **Performance Optimized**: Fast loading with minimal dependencies
- **Accessibility**: Built with accessibility best practices

## Sections

- **Hero**: Eye-catching introduction with call-to-action buttons
- **About**: Personal information and skills showcase
- **Projects**: Portfolio of work with project cards and tags
- **Contact**: Contact information and interactive form

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Google Fonts (Inter)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Ethan-MKatz/myWebsite.git
   ```

2. Navigate to the project directory:
   ```bash
   cd myWebsite
   ```

3. Open `index.html` in your web browser or serve it using a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```

4. Visit `http://localhost:8000` in your browser

## Customization

To customize the website for your own use:

1. **Update Content**: Edit the text content in `index.html`
2. **Change Colors**: Modify the CSS variables and color schemes in `styles.css`
3. **Add Projects**: Update the projects section with your own work
4. **Contact Information**: Replace placeholder contact details with your own
5. **Fonts**: Change the Google Fonts import in the HTML head section
